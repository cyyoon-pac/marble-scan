# 마블 스캔

소고기 단면 사진으로 마블링·육색·지방색을 분석해 한우 육질등급 구간을 추정하는 웹앱(PWA) 프로토타입입니다.

- 앱 주소: https://cyyoon-pac.github.io/marble-scan/
- 휴대폰 브라우저에서 열고 공유 메뉴의 "홈 화면에 추가"를 누르면 앱처럼 설치됩니다.
- 사진은 기기 안에서만 처리되고 외부로 전송되지 않습니다.
- 결과는 추정치이며 축산물품질평가원의 공식 등급이 아닙니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면, 촬영, 판정 표시, 사진 저장 |
| `scan-core.js` | 분석 엔진: 지방 판별, 근육 덩어리 분할, 떡심 검출 |
| `sw.js` | 오프라인 캐시 |
| `manifest.webmanifest` | 홈 화면 설치 정보 |

## 판정 방식 (v0.4)

- AI허브 '축산물 품질(QC) 이미지'의 실제 등급 판정 사진 400장(3등급 100, 2등급 50, 1등급 100, 1+ 50, 1++ 100)으로 판정식을 보정했습니다.
- 지표: 지방 면적 지수(사진 밝기 기준 상대 판별, 등심 가장자리 제외), 결의 섬세함, 미세 지방 입자 밀도, 살코기 붉은 기
- 교차검증: 5개 등급 정확히 맞힘 43%, ±1등급 이내 78%
- 여러 팩 비교: 한 사진 안의 여러 팩을 같은 기준으로 점수화해 순위를 매깁니다. 조명·카메라 차이가 상쇄됩니다.
